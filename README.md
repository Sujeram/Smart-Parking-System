# Smart Parking System

## About

This project is a Smart Parking System developed using Java, Spring Boot and Thymeleaf. It helps manage parking operations by allowing users to register customers, reserve parking spaces, park vehicles, process payments and view parking availability. The project includes both a web application and a console-based version.

## Features

- Customer registration
- Vehicle parking
- Parking reservation
- Automatic parking space allocation
- Ticket generation
- Payment calculation
- Parking availability tracking
- Reports and parking statistics

## Technologies Used

## How to Run

1. Install Java 17 or later.
2. Install Apache Maven.
3. Download or clone this repository.
4. Open the project in your preferred IDE.
5. Run the following command:

```
mvn spring-boot:run
```

6. Open your browser and visit:

```
http://localhost:8080
```
